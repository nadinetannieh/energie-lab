6. 🧠 Je construis la connaissance

À partir de tes observations, retiens les relations fondamentales suivantes.

Epp = −mgz + C

où :

  • m est la masse du corps ;
  • g est l'intensité de la pesanteur ;
  • z est l'altitude ;
  • C est une constante dépendant du choix de l'origine de l'énergie potentielle.
WA→B(P) = − ΔEpp

avec :

ΔEpp = Epp(B) − Epp(A)
